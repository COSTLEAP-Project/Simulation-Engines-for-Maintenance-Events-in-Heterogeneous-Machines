# Illustrative Examples

This folder contains the synthetic datasets used in the illustrative examples of the paper:

**Simulation Engines for Maintenance Events in Heterogeneous Machines**

The datasets are generated by the proposed TBM and CBM simulation engines and are provided to support reproduction of the illustrative analyses in Sections 5.2 and 5.3.

## 1. TBM illustrative example

The TBM example considers a fleet of vehicles operating under heterogeneous road conditions. Each vehicle is assigned a gravel-road percentage, which affects its failure hazard through a proportional-hazards model.

**File:** `tbm_car_fleet_mileage_event_log.csv`

The simulation parameters used to generate this dataset are specified in the corresponding example code. These parameters define the data-generating process only and are treated as unknown in the subsequent estimation and optimization analysis.

## 2. CBM illustrative example

The CBM example simulates brake-system degradation for a fleet of vehicles under heterogeneous operating conditions.

The dataset is used to evaluate RUL prediction models under two information settings: using observable features only, and using observable features together with the noisy observed degradation signal.

**File:** `cbm_complete_df_train.csv`, `cbm_complete_df_test.csv`

The true degradation process and failure threshold are known by construction, allowing prediction models to be evaluated in a controlled setting.
